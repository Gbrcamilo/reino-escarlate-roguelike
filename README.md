# Reino Escarlate

Roguelite de ação 2D original, feito com TypeScript e Canvas 2D. A protagonista Liora usa a **Visão da Fissura** para revelar nós vulneráveis em criaturas de um conto de fadas corrompido.

## Estado atual

O projeto inclui um vertical slice leve e jogável:

- Movimento em oito direções
- Ataque corpo a corpo
- Esquiva com invencibilidade breve
- Inimigo perseguidor com vida e ataque
- Visão da Fissura e acerto crítico no nó vulnerável
- HUD de Vida e Fôlego Carmesim
- Partículas, feedback de dano e tela de derrota

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Controles

| Tecla | Ação |
|---|---|
| WASD | Mover Liora |
| J | Atacar |
| Espaço | Esquivar |
| F | Segurar para ativar a Visão da Fissura |
| R | Reiniciar a arena |
